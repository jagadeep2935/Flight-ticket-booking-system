# ✈️ Global Flight Booking

A simple and responsive flight ticket booking website developed using **HTML and CSS** as a first-year B.Tech project. The website features a flight booking interface, a booking form, and an available flights table, with styling and animations to create an engaging user experience.

## 📌 Project Overview

Global Flight Booking is a frontend web development project designed to demonstrate the fundamentals of website structure, styling, and user interface design. It provides a basic flight booking interface where users can explore the displayed flight information and interact with the booking form.

## ✨ Features

- **Flight Booking Form** – A user-friendly interface for entering flight booking details.
- **Available Flights Table** – Displays flight information in a structured tabular format.
- **Visual Design** – Uses CSS to style the website and organize its layout.
- **CSS Animations** – Adds simple animations for a more engaging experience.
- **Flight-Themed Interface** – Includes airplane imagery to complement the website's design.

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage and its content.
- **CSS3** – Handles styling, layout, and animations.

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation or dependencies are required.
